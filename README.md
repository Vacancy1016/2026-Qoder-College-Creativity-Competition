# 大学航线 · 产品流程与技术框架

[打开在线演示](https://vacancy1016.github.io/2026-Qoder-College-Creativity-Competition/)

这份 13 页的方案展示了大学生如何从就业目标出发选课，把课程作业积累为可核验的项目证据，并用于撰写简历和筛选实习岗位。

第 1 页介绍痛点与解决办法，第 2 页为可点击的总体流程图，第 3 页说明数据基础，第 4 至 11 页逐步分析实现方式、技术和数据，第 12 页介绍可选的智能问答，第 13 页总结首版范围。

用左右方向键翻页，或通过目录跳转。可直接打开或编辑根目录的 `index.html`。GitHub Pages 从 `main` 分支根目录发布。
